Data Inventory

The working state of place-based data discovery: every dataset assessed so far, what has been checked, and what is still open. Details and roadmap on GitHub

How to read the tiers
Gold
Link, page, licence, spatial unit, years and access all pass, read from the publisher’s pages with evidence.
Silver
The link works and no check fails, but at least one is only partly confirmed (a warning).
Bronze
The link works, but the content has not been read yet, or a check failed (often a licence the page does not state).
Browser needed
The site blocks automated checks; a person needs to open it. Usually not a dead link.
Failed
Dead, withdrawn, archived, or data that ends before 2000.
Verified: page / file
“page” means the facts come from the publisher’s pages; “file” means a real file was opened and its columns, place key and years read.

US federal datasets pass the licence check by the working group’s rule (public domain unless a page says otherwise).
