Tiers come from the checks in each row (link, page, licence, unit, years, access). “Page” verified means the facts were read on the publisher’s pages; “file” means a real file was opened and its columns, place key and years read. US federal datasets pass the licence check by the working group’s rule (public domain unless a page says otherwise).

Show as a table

The coloured areas are the inventory: each point is one saved run (the master file after that iteration; numbers point to the iterations table on GitHub). Counts are today’s datasets present at that run (stacked by their category, or by the tier they had then), so filters on the left apply here too. 3 rows trimmed on 28 Oct are not shown. Under Last 3 months, the dark line before October is the gaiaCatalog itself (dataset folders in its repository, from its git history); it covers the whole catalog, so it shows only while no filter is on.
