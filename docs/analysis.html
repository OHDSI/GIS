OHDSI GIS WG

Analysis Capabilities and Future Directions

The OMOP GIS extension supports analyses beyond traditional clinical observational research. This page summarizes the analysis tools available now, the extensions the working group has proposed, and the methodological and ethical needs of geospatially informed health research. The proposed items are plans, not released software.


Current analysis infrastructure

Tool Role Limits for GIS use cases
ATLAS Primary user interface for OMOP analytics: cohort construction, characterization, prediction Limited support for spatial exposure variables from external_exposure, geographic visualization, multi-level modeling, temporal exposure sequences and spatial statistics
HADES Open-source R packages that form the analytical foundation of OHDSI Used directly for GIS work today: SQL access to external_exposure, flexible feature engineering from spatial and environmental variables, causal inference and prediction, network studies across sites

GIS use cases currently work through HADES and custom scripts. The tutorial shows this end to end with CaprForExtensions and FeatureExtractionForExtensions, and gaiaCore provides exposure analytics from R.

Extensions would follow the OHDSI contribution path: prototype, community review at working group meetings and symposia, validation across use cases and datasets, documentation (vignettes, function reference, validation reports), testing to HADES standards, submission through OHDSI governance, and long-term maintenance.

Future directions

Direction Examples
Community-driven development Use cases identify analytical needs; HADES package proposals come from validated use cases; community review checks scientific and ethical standards (see use case status)
Emerging methods Causal inference for spatial exposures (spatial instrumental variables, regression discontinuity)
Machine learning for exposure prediction (satellite imagery, land use)
Agent-based modeling of neighborhood effects
Precision environmental health
Cross-disciplinary collaboration Environmental science, geography and GIS, urban planning, social epidemiology, ethics and philosophy
Open science Apache 2.0 licensed extensions, vignettes on public data, published validation studies, feedback through GitHub, forums and working group meetings
